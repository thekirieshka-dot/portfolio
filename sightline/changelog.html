(Changelog)Current: v38 · Week 39

Shipped, in order.

Every release since Week 22, newest first. Nothing on this page is a roadmap: if it is here, it is in your workspace.

v38Week 39Latest

A receipt shows the metric definition, the source table, rows scanned, runtime and freshness. It is the same record the audit log keeps, so the number on screen and the number in the log can never drift apart. If Sightline cannot show its working, it no longer shows the figure.

  • Answers
  • Slack
  • Dashboards

Most of the saved half second was the planner re-reading metric definitions it had read a minute earlier. The cache invalidates the moment an analyst merges a change, so definitions are never stale.

4.6 s4.1 s

  • Planner

Schedules are now stored as a local time plus a zone name, not a fixed offset. Affected workspaces were corrected without anyone needing to re-save their schedules.

  • Schedules
v37Week 38

A budget is set per workspace and can be overridden per source. The asker sees the estimate before the query runs, and the approver sees the SQL. Queries inside the budget are unaffected.

  • Governance
  • Connectors

Planning on tables with more than 400 columns is 3.1 times faster, and the generated SQL now prunes partitions on the first attempt.

2.7 s0.9 s

  • Connectors
v36Week 37

If a thread is already discussing a metric, Sightline reads the last twenty messages for definitions and filters before it plans. It posts the answer in the thread and keeps the receipt one click away.

  • Slack

Both answers used to appear, and both counted towards your question allowance. Duplicates from the last 30 days were credited back automatically.

  • App
v35Week 36

Analysts now see the old and new SQL next to each other, plus the five most-asked questions whose results would move, with the before and after values.

  • Semantic layer

An off-by-one in the export paginator. It affected 14 workspaces, all of whom were told directly and given a corrected export.

  • Export

The semantic layer now accepts a calendar definition. Existing workspaces were migrated, and the old behaviour is preserved where an analyst had already worked around it.

  • Semantic layer
v34Week 35

Switch it on per table in the semantic layer. Suppressed groups are named in the answer, so nobody wonders why the numbers do not add up.

  • Governance

Pick “Enterprise” as blue once and it stays blue everywhere it appears. Colours are stored on the metric, not on the chart.

  • Charts
v33Week 34

Tokens are scoped to a workspace and a role, and every call is written to the audit log. Rate limits are 600 requests a minute, and answers cached within 24 hours are free.

  • API

The connector waited on the reservation as if it were query runtime. It now shows queued time separately and keeps the job alive for up to ten minutes.

  • Connectors
v32Week 33

The choice is stored per person, not per workspace, and is visible in the receipt. Analysts can see which ambiguities come up most and fix them at the source.

  • Planner
v31Week 32

Keys live in your key-management service. Sightline holds a wrapped data key and never the key itself. Revocation takes effect within minutes, not at the next rotation.

  • Security

The link survives the round trip through your identity provider, including when the answer belongs to a different workspace than your last one.

  • Identity

Rotating a read-only credential now clears the cache for that source immediately.

  • Connectors
v30Week 31

Sections have their own permissions, so a finance block can be visible to six people while the rest of the dashboard is open to everyone.

  • Dashboards

Most weeks ship a fix nobody noticed.

Nine more releases below
v29Week 30

Every implicit filter from the semantic layer is listed under the sentence, with the metric file that defines it. Click one to see the definition.

  • Answers

Charts are now rendered as images with a text fallback that carries the numbers.

  • Slack
v28Week 29

Embeds show the receipt on hover and respect the viewer’s permissions, so a number a reader may not see is replaced by a lock, not by a stale value.

  • Docs
v27Week 28

We moved from batched delivery to a per-entry queue. Ordering is preserved, and each entry carries a sequence number so gaps are detectable.

40 s6 s

  • Security

Search is accent- and case-insensitive across question history, saved answers and metric names.

  • App
v26Week 27

Add someone to the group in your identity provider and their role changes within a minute. Remove them and access ends in the same minute.

  • Identity
v25Week 26

The connector reads catalog tables once and infers joins from foreign keys and from the last 90 days of query history, instead of probing every pair.

6 min40 s

  • Connectors

Four workspaces had metrics that exported but could not be re-imported. All four were repaired.

  • Semantic layer
v24Week 25

Owners get a short note when an answer has not been opened for 90 days. One click keeps it, and one click archives it.

  • Answers
v23Week 24

You no longer have to name the steps in sequence. Sightline checks the order against the last 30 days of data and tells you when events arrive out of order.

  • Planner

Schedules now follow the channel’s ID, not its name.

  • Slack
v22Week 23

The first release of the semantic layer as code: YAML files, branches, pull requests and a diff of what a change would do to existing answers.

  • Semantic layer

It used to wait for a manual click. 71% of new workspaces now have a dashboard on day one.

  • Dashboards
v21Week 22

Postgres row-level policies and BigQuery authorised views are respected automatically. The audit log records which role ran each query.
