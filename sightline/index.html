    (02)How it works

    Three steps. Two of them take seconds.

    1. 01 / Connect

      Point it at the data you already have.

      Warehouse, billing, product events, CRM. Read-only credentials, 40+ connectors, about eleven minutes. Sightline drafts a semantic layer from your schema and query history; your data team reviews it like any other pull request.

      • Read-only, checked on every connect
      • Schema mapped automatically
      • Metric definitions versioned in git
    2. 02 / Ask

      Type the question the way you’d ask a colleague.

      You get a chart, a two-sentence answer, the reasoning and the SQL it ran. If the question is ambiguous, Sightline asks which “active” you meant instead of guessing.

      • Median answer 4.1 s
      • Uses your analysts’ definitions
      • Says “no answer” when there isn’t one
    3. 03 / Share

      Send the answer, not a screenshot.

      Links stay live, comments stay attached, and anyone with access can open the query and check the maths. Schedule it to Slack every Monday and stop being the person who pastes the numbers.

      • Live links with comments
      • Scheduled posts to Slack and Docs
      • Permissions inherited from the warehouse

    (05)Security
    
    
    Read-only. On purpose.
    
    
    Sightline can look at everything you allow and touch nothing. We built it so the security review takes one meeting, not one quarter.
    
    
    Read the full security sheet

GRANT USAGE  ON SCHEMA analytics TO sightline_ro;
GRANT SELECT ON ALL TABLES IN SCHEMA analytics
      TO sightline_ro;

-- anything wider and it refuses to connect:
INSERT UPDATE DELETE ALTER DROP TRUNCATE
